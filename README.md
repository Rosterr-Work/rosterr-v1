# Rosterr (archived)

**This repository is archived and no longer maintained.** It is published for reference only. It gets no updates or security fixes,
and it should not be used in production.

Rosterr is HR for Roblox groups: staff, ranks and permissions, sessions, activity, moderation and hiring. The current product is
at [rosterr.cc](https://rosterr.cc).

## What is in this repository

Rosterr began in September 2026 as a fork of [Firefli](https://github.com/TeamFirefli/Firefli). Firefli is based on
[Orbit](https://github.com/PlanetaryOrbit/orbit), which is based on the original Tovy project.

This repository holds Rosterr's modified versions of the files that came from that codebase, as they stood when this version of
Rosterr was retired. Parts of Rosterr that were written separately, and were never part of the Firefli codebase, are not included.
Some files here import those parts, so this code does not build or run on its own.

See [`NOTICE.md`](./NOTICE.md) for what was changed and where it came from.
