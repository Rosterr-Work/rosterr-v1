# Security policy

This repository is archived. It gets no updates or security fixes, and it should not be used in production.

If you find a security problem that affects Rosterr as it runs today at [rosterr.cc](https://rosterr.cc), please report it
privately through this repository's **Security** tab (**Report a vulnerability**), not in a public issue. Include what you found,
how to reproduce it, and what it let you read or change.

Please don't test against workspaces or accounts that aren't yours, and don't read, change or delete other people's data.
